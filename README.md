# Jify

> A simple, customizable, and browser-based JSON builder & formatter.

# English

## About

Jify is a lightweight JSON builder and formatter created to make working with JSON easier, faster, and more visual.

Working with raw JSON can sometimes become frustrating, especially when dealing with nested objects, arrays, quotes, commas, and large amounts of data. Jify provides a visual interface that makes it easier to create, edit, organize, and preview JSON without having to manually manage every part of the syntax.

The main idea behind Jify is simple: make JSON easier to work with without adding unnecessary complexity.

Jify runs entirely on the client side, meaning your data can be processed directly inside your browser without requiring a backend server or database.

## Features

### JSON Builder

Create JSON data through a visual interface instead of writing everything manually.

You can:

- Add new keys and values
- Edit existing data
- Remove data
- Create nested structures
- Work with different JSON value types
- Organize your JSON structure visually

### JSON Preview

Jify provides a real-time preview of the generated JSON.

Changes made inside the builder can be reflected immediately in the output, making it easier to check the structure of your data while working.

### Import & Export

Jify supports working with existing JSON files as well as exporting your finished data.

You can:

- Import existing JSON
- Edit imported data
- Preview the result
- Export the final JSON

### Workspace

Jify includes workspace functionality for managing your current editing session.

Your workspace can be stored locally using the browser's LocalStorage, allowing you to continue working without requiring an online account.

### Editing Tools

Jify also includes several tools designed to make editing easier:

- Undo
- Redo
- Search
- Data organization
- JSON statistics
- Keyboard shortcuts
- Workspace saving

## Privacy

Jify is designed around client-side processing.

Your JSON data does not need to be uploaded to a remote server for the main builder functionality to work.

Workspace information is stored locally through your browser's LocalStorage.

Because the project operates directly in the browser, Jify does not require a user account or database for its core functionality.

## Technology

Jify is built using standard web technologies:

- HTML
- CSS
- JavaScript
- SVG
- LocalStorage

There is no required backend server or database.

The goal is to keep Jify lightweight, portable, and easy to run.

## Design

The interface was designed with a clean and modern approach while keeping the main tools easy to access.

The project uses:

- Responsive layouts
- Bento-style UI elements
- Modern cards and panels
- Smooth interactions
- Custom SVG elements
- Responsive design for different screen sizes

## Getting Started

Jify does not require a complicated setup.

Simply clone or download the repository and open the main HTML file in a modern web browser.

```bash
git clone <repository-url>
````

Then open:

```text
index.html
```

in your browser.
